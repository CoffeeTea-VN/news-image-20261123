# The World in One Day — Monday 23 November 2026

One image that sums up a single day's world news, drawn and typeset in code
(a Python/PIL drawing script) so every word stays legible: COP31 climate
talks collapse with no deal in Antalya, Russian strikes hit homes near Kyiv,
a Russian warship is hit in a Libyan port, US Democrats clinch their biggest
House majority since 1992, an AI sell-off rocks world markets, and dozens
are missing in an Indonesian factory fire.

`main.ts` installs the finished picture (`entry.png`, 1024×1024) as the
entry's output at `/output/entry.png`.
